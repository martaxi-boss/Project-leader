# Source patterns

This control plane is an adaptation, not a wholesale copy, of official OpenAI examples.

## Workspace Agent pattern

OpenAI Cookbook:
`articles/chatgpt-agents-sales-meeting-prep.md`

Repository:
`openai/openai-cookbook`

Relevant idea: a ChatGPT Business Workspace Agent can own a repeatable end-to-end workflow, use connected apps/tools, run on demand, and be configured through the conversational Agent Builder.

## Project Manager orchestration pattern

OpenAI Cookbook:
`examples/codex/codex_mcp_agents_sdk/building_consistent_workflows_codex_cli_agents_sdk.ipynb`

Repository:
`openai/openai-cookbook`

Relevant idea: a Project Manager receives the initial request, coordinates specialist roles, verifies required evidence, and enforces gatekeeping before moving to the next stage.
